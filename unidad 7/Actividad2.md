En tu resumen debes tratar de conectar GLFW, opengl32.lib, GLAD, GLM y los drivers de la GPU. ¿Qué rol cumple cada uno? ¿Cómo se relacionan entre sí? Además, si no recuerdas algo quiere decir que no lo entendiste bien y eso es una buena señal para que vuelvas a leerlo.

- opengl creo que es una forma de comunicarme con la tarjeta grafica, pero necesita que varias cosas trabajen juntas para hacer algo visual

- el GLWF es la ventana y la que maneja los controles como teclas, controles, mouse.

- opengl32.lib ayuda a a iniciarlo y solo para ello ya que no tiene funciones modernas.

- GLAD por lo que entiendo, busca los drivers en la gpu y esto permite usar la version moderna de OpenGL ya que por defecto viene sin estos drivers implementados

- GLM  es una libreria matematicas para graficos, ayuda para posiciones, direcciones, rotaciones, escalas

- *adicionalmente*:

- .lib se usa para compilar 
- .dll se usa cuando se ejecuta y contiene el codigo real.
